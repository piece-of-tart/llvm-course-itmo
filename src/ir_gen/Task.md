# Третье задание (до 22.10 23:59)

## Основная задача

Написать (или сгенерировать) **IR-генератор графического приложения** и подключить **интерпретацию** через `ExecutionEngine` с **пробросом графических функций** в рантайм.

Требования:

* IR генерируется программно (через LLVM API) **или** берётся готовым/сгенерированным, но должен быть корректно загружен/собран в `Module`.
* Приложение выполняется через `ExecutionEngine` (Interpreter / JIT — по выбору, но интерпретация должна быть подключена).
* Графические функции должны быть доступны во время исполнения (например: `Graphics_put_pixel`, `Graphics_flush`), и должны быть замаплены/разрешены в `ExecutionEngine`.

## Артефакты

* Код IR-генератора + запуск через `ExecutionEngine` → **в репозиторий**
* (Опционально) пример вывода/демо работы (скрин/лог) → **в репозиторий**
