# Второе задание (до 8.10 23:59)

## Основная задача
Используя инструментирующий Pass, собрать во время выполнения:
- Трассу выполненных IR инструкций
- Трассу использования инструкций (User ← Operand)

Для графического приложения (только модуль логики - `app.c`), скомпилированного с уровнями оптимизации `-O1`, `-O2`, `-O3` и `-s`.

**Примечание:** Пропустить User, если это инструкция `phi*`.

**Артефакты:**
- Код реализации Pass → репозиторий
- Анализ часто повторяющихся паттернов (длина паттерна: 1-5 инструкций) → репозиторий

## Бонусная задача (★)
При поиске операнда из инструкции `phi`, вывести инструкции, используемые в операндах phi.

**Пример:** Запись `shl ← phi` заменяется двумя записями:
- `shl ← add`
- `shl ← sub`

(если данный `phi` использует `add` и `sub` как операнды)
